# Documentation

Docs are grouped by audience and use.

- `project/`: product direction, PRDs, handoffs, and planning records.
- `agents/`: instructions for coding agents working in this repo.
- `research/`: benchmark methodology, source notes, and critique of existing benchmark standards.
- `data/`: data retention, run output schema, and derived dataset notes.
- `domain/`: music theory and Euterpea/Haskell domain references.
- `compliance/`: mapping to certification, evaluation, and benchmark-quality standards.
- `site/`: public website or documentation site planning.
